# Sigaa Scraper

Biblioteca Python para scraping do portal discente do **SIGAA UFG**.

Extrai perfil acadêmico, matérias, atividades avaliativas e atualizações de turma a partir de uma sessão autenticada — sem precisar de credenciais, apenas dos cookies do navegador.

## Instalação

```bash
pip install git+https://github.com/lvlassis/sigaa-scraper.git
```

## Requisitos

- Python 3.12+
- Cookies de uma sessão ativa no SIGAA UFG

## Aviso de uso

> Esta biblioteca acessa apenas os dados do próprio usuário autenticado.
> Não a utilize para acessar dados de terceiros ou para realizar requisições
> em volume que possam sobrecarregar os servidores do SIGAA.
